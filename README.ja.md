# Pyxel Dungeon

[English](README.md)

[Pyxel](https://github.com/kitao/pyxel) 3 と、その 3D 機能 Pyxel Cube で作っている、リアルタイムの一人称ダンジョン RPG。往年のパーティー制ダンジョンゲームにならいつつ、2 点を変えている。敵とアイテムは平面の絵ではなく 3D モデルで描く。移動はマス単位ではなく自由に動ける。

**ブラウザで遊ぶ: https://ryohji.github.io/pyxel-dungeon/**

制作中。いまあるのは、2 つの階、小さな謎解き（レバー、感圧床、鍵のかかった扉）、骨の番兵、AI の仲間。キャラクターまわりもある。能力値、使うほど伸びる 4 つの技能、装備と持ち物、空腹と渇き、燃え尽きていく松明。ルーン魔法もある。

主題は「持ち帰る」こと。潜って帰るを繰り返して進める。ダンジョンの入口にある野営地（選択式の 1 画面）から始まる。潜る前に依頼の一覧を見て受け（ダンジョンの中で書き置きから受けることもある）、下りていって、頼まれた物を持ち帰る。なくした指輪、石の像、帰ってこなかった冒険者の亡骸など。野営地に帰ると、頼まれた品はひとりでに渡され、パーティーは休み、今回持ち帰った物が一覧で示される。報酬の硬貨は「補給」で松明や食料に替え、骨を鍛冶屋に持ち込めば槌を作ってもらえる。アルンの武器は武器棚で選ぶ。速い剣、長いが遅い槍（荷を背負うと使えない）、石を砕く槌。技能は使うほど育つが慣れ 5 段までで、それより先の強さは持ち帰った物で決まる。また潜る。亡者は潜るたびによみがえるが、開けた扉や置いた物はそのまま残る。古い縦穴を一度登れば、次からは野営地からそこへ直接下りられる。重い物はアルンが背負う。背負っている間は歩みが遅くなり、走れず、剣も弱い。戦う前に下ろしておくとよい。

地下室は、丘の下に眠る古い王国の遺構だった。3 つの階に 5 つの遺物があり、壁の碑文が王国の物語を伝える。遺物の行き先はひとつずつ選べる。野営地の学者ヴェスクに渡せば王国の力がよみがえる（古い燭台に火が戻るが、石の守護者が目を覚ます）。封印の壁龕に納めれば永遠に葬られる（闇が深まるが、亡者の一部が崩れ去る）。野営地の墓守は葬ることを望んでいる。5 つすべての行き先が決まると、丘が物語の結末を決める。制作計画は [PLAN.md](PLAN.md) にある。

## 操作

| 入力 | 動作 |
|---|---|
| W A S D | 移動（Shift を押しながらで走る） |
| Q E / ← → | 向きを変える |
| ↑ ↓ | 見上げる・見下ろす（R で水平に戻す） |
| 右ドラッグ | 見回す |
| 左クリック | マウスで指した物に働きかける（攻撃、拾う・背負う、レバーを引く、扉を開け閉めする、泉で水を飲む） |
| 背負っているときに床を左クリック | 背負った物を下ろす |
| 物を持っているときの左クリック | 床なら置く、錠なら鍵を使う、泉なら水袋を満たす、それ以外なら投げる |
| Tab | キーボードで対象を選ぶ（押すたびに次へ。かぎ括弧で示す） |
| Space | 対象に働きかける。対象は Tab で選んだ物か、マウスで指した物のうち、後から操作したほう。働きかける物がなければ、正面の敵に斬りかかる |
| G | 大技。番兵の教本（2 階）を持ち帰ると使える。剣は前の敵をまとめて薙ぎ払い、槍は一列に突き通し、槌は周りの敵を揺さぶる |
| 1 2 3 4 | 画面下のパネルからルーンを選ぶ。強さ、属性、形の順（クリックでも選べる） |
| Enter | ルーンを唱える（Backspace で最後のルーンを取り消す） |
| I、またはパーティーの欄をクリック | 持ち物（装備、持ち物の整理、食べる・飲む。開いている間は一時停止） |
| J | 覚え書き。「人の話」「遺物」（それぞれの行方つき）「碑文と書き置き」の 3 冊に分かれている（Tab か 1〜3 で本を選び、← → でページをめくる） |
| M | 地図（目覚めた石の守護者を青い四角で示す） |
| L | 言語の切り替え（日本語。English にもできる） |
| F | 開発用の表示（処理時間と fps）。表示中は、F5 で CSV と今の階のマップを読み直す、F6 で傷を受けない、F7 / F8 で上 / 下の階へ移る、F9 で手に次の種類の物を持つ |
| H | ヘルプ（開いている間は一時停止。Esc やクリックでも閉じる） |
| ウィンドウを閉じる | 終了（Esc では終了しない） |

プレイヤーは前衛のアルン。仲間のミラは、魔力を使って、見えている敵に魔法の弾を撃ち、傷を癒やす（操作はいらない）。全滅すると、墓守が野営地まで運んでくれる。ただし、アルンが背負っていた物と手に持っていた物は倒れた場所に残る（地図に印が出る）。取りに戻ればよい。

野営地では 1〜8、Tab か ↑ ↓ と Space、またはマウスで選ぶ。野営地を出るときと帰ったときに、ひとりでにセーブする（デスクトップ版は `~/.pyxel/ryohji/pyxel-dungeon/save.json`。消せば最初から遊べる）。

2 人とも 4 つの技能（戦士、忍者、僧侶、魔術師）を持ち、使うほど上がる。剣で斬れば戦士、投げて当てれば忍者、癒やせば僧侶、魔法の弾を当てれば魔術師が伸びる。走ったり剣を振ったりするとスタミナが減る。食料と水は時間とともに減る。持ち物の画面で、食べ物を口の欄に置くと食べる。水は水袋か泉から飲む。松明が燃え尽きかけると、見える範囲が暗くなる。

アルンはルーン魔法を使う。魔法は 3 つのルーンで決まる。強さ（1〜4。魔力の消費と効果を何倍にするか）、属性（炎・氷・光・命）、形（弾・守り・爆発・壁）。たとえば、炎と弾で火の玉、氷と壁で氷の壁、光と守りで松明なしの明かり、命と爆発でパーティー全体の回復になる。弾は選んでいる敵に向かって飛び、選んでいなければ正面に飛ぶ。強さのルーンは、唱える人の技能（魔術師。命の属性は僧侶）より 1 段階上までしか使えない。それを超えると不発に終わる。

**遊ぶ前に、日本語入力をオフにすること。** 日本語入力がオンのままだと、押し続けたキーが入力途中の文字として溜まり続け、ゲームが重くなる。デスクトップ版は macOS と Windows で自動的に英字入力へ切り替えるが、ブラウザ版はできない。

## 手元で動かす

Python 3.11 以上が必要（Pyxel 3 の要件）。

```sh
python -m venv .venv
.venv/bin/pip install pyxel==3.0.0
cd game && ../.venv/bin/python main.py
```

## 構成

| 場所 | 内容 |
|---|---|
| `game/` | ゲーム本体。`main.py` から始まる。ほかに、世界、パーティー、敵、描画 |
| `game/data/` | 調整するための数値（CSV）。仲間の能力値、技能の段階と伸び、アイテム、初期装備、魔法、依頼、店の品、遺物と物語の文章、敵、空腹の速さやヒットストップなどの値。読み込みは `game/tables.py`。日本語の文章は各 CSV の `*_ja` の列と `text.csv` にある（`game/lang.py`） |
| `game/maps/` | 階のマップ（テキスト）。書式は `game/dungeon.py` の冒頭に書いてある |
| `game/sfx/` | 効果音。`tools/make_sfx.py` で生成する |
| `game/test_p2.py` 〜 `game/test_p10.py`、`game/test_story.py`、`game/test_feedback.py` | 謎解き、戦闘、キャラクターまわり、魔法、野営地、物語、ヒットストップ、開発用のキー、日本語、潜って帰る流れ（野営地の画面、全滅、縦穴、セーブ）、成長（武器、大技、鍛冶、慣れ）の試験。画面を出さずに動く |
| `tools/` | 効果音の合成と、処理時間の計測 |
| `p0/` | 描画方式を決めた計測 |

`main` に push するたびに、ブラウザ版が作られて GitHub Pages に公開される（`.github/workflows/pages.yml`）。
