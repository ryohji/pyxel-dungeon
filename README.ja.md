# Pyxel Dungeon

[English](README.md)

[Pyxel](https://github.com/kitao/pyxel) 3 と、その 3D 機能 Pyxel Cube で作っている、リアルタイムの一人称ダンジョン RPG。往年のパーティー制ダンジョンゲームにならいつつ、2 点を変えている。敵とアイテムは平面の絵ではなく 3D モデルで描く。移動はマス単位ではなく自由に動ける。

**ブラウザで遊ぶ: https://ryohji.github.io/pyxel-dungeon/**

制作中。いまあるのは、2 つの階、小さな謎解き（レバー、感圧床、鍵のかかった扉）、骨の番兵、AI の仲間。キャラクターまわりもある。能力値、使うほど伸びる 4 つの技能、装備と持ち物、空腹と渇き、燃え尽きていく松明。ルーン魔法もある。制作計画は [PLAN.md](PLAN.md) にある。

## 操作

| 入力 | 動作 |
|---|---|
| W A S D | 移動（Shift を押しながらで走る） |
| Q E / ← → | 向きを変える |
| ↑ ↓ | 見上げる・見下ろす（R で水平に戻す） |
| 右ドラッグ | 見回す |
| 左クリック | マウスで指した物に働きかける（攻撃、拾う、レバーを引く、扉を試す、泉で水を飲む） |
| 物を持っているときの左クリック | 床なら置く、錠なら鍵を使う、泉なら水袋を満たす、それ以外なら投げる |
| Tab | キーボードで対象を選ぶ（押すたびに次へ。かぎ括弧で示す） |
| Space | 対象に働きかける。対象は Tab で選んだ物か、マウスで指した物のうち、後から操作したほう。働きかける物がなければ、正面の敵に斬りかかる |
| 1 2 3 4 | 画面下のパネルからルーンを選ぶ。強さ、属性、形の順（クリックでも選べる） |
| Enter | ルーンを唱える（Backspace で最後のルーンを取り消す） |
| I、またはパーティーの欄をクリック | 持ち物（装備、持ち物の整理、食べる・飲む。開いている間は一時停止） |
| M | 地図 |
| F | 情報表示（処理時間と fps） |
| H | ヘルプ（開いている間は一時停止。Esc やクリックでも閉じる） |
| ウィンドウを閉じる | 終了（Esc では終了しない） |

プレイヤーは前衛のアルン。仲間のミラは、魔力を使って、見えている敵に魔法の弾を撃ち、傷を癒やす（操作はいらない）。全滅すると、その階に入ったところからやり直しになる。

2 人とも 4 つの技能（戦士、忍者、僧侶、魔術師）を持ち、使うほど上がる。剣で斬れば戦士、投げて当てれば忍者、癒やせば僧侶、魔法の弾を当てれば魔術師が伸びる。走ったり剣を振ったりするとスタミナが減る。食料と水は時間とともに減る。持ち物の画面で、食べ物を口の欄に置くと食べる。水は水袋か泉から飲む。松明が燃え尽きかけると、見える範囲が暗くなる。

アルンはルーン魔法を使う。魔法は 3 つのルーンで決まる。強さ（1〜4。魔力の消費と効果を何倍にするか）、属性（炎・氷・光・命）、形（弾・守り・爆発・壁）。たとえば、炎と弾で火の玉、氷と壁で氷の壁、光と守りで松明なしの明かり、命と爆発でパーティー全体の回復になる。弾は選んでいる敵に向かって飛び、選んでいなければ正面に飛ぶ。強さのルーンは、唱える人の技能（魔術師。命の属性は僧侶）より 1 段階上までしか使えない。それを超えると不発に終わる。

**遊ぶ前に、日本語入力をオフにすること。** 日本語入力がオンのままだと、押し続けたキーが入力途中の文字として溜まり続け、ゲームが重くなる。デスクトップ版は macOS と Windows で自動的に英字入力へ切り替えるが、ブラウザ版はできない。

## 手元で動かす

Python 3.11 以上が必要（Pyxel 3 の要件）。

```sh
python -m venv .venv
.venv/bin/pip install pyxel==3.0.0
cd game && ../.venv/bin/python main.py
```

## 構成

| 場所 | 内容 |
|---|---|
| `game/` | ゲーム本体。`main.py` から始まる。ほかに、世界、パーティー、敵、描画 |
| `game/data/` | 調整するための数値（CSV）。仲間の能力値、技能の段階と伸び、アイテム、初期装備、魔法、空腹の速さなどの値。読み込みは `game/tables.py` |
| `game/maps/` | 階のマップ（テキスト）。書式は `game/dungeon.py` の冒頭に書いてある |
| `game/sfx/` | 効果音。`tools/make_sfx.py` で生成する |
| `game/test_p2.py` 〜 `game/test_p5.py` | 謎解き、戦闘、キャラクターまわり、魔法の試験。画面を出さずに動く |
| `tools/` | 効果音の合成と、処理時間の計測 |
| `p0/` | 描画方式を決めた計測 |

`main` に push するたびに、ブラウザ版が作られて GitHub Pages に公開される（`.github/workflows/pages.yml`）。
